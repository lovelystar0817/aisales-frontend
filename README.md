# AI Sales Training Frontend

The frontend application for the AI Sales Training Platform, built with React and Vite. It provides an interactive interface for sales trainees to engage in AI-driven roleplay scenarios and receive real-time feedback.

## 🚀 Features

- **Interactive Roleplay**: Real-time voice interaction with AI avatars.
- **Instant Feedback**: Automated scoring and analysis of sales performance.
- **Progress Tracking**: Detailed dashboards for users and admins.
- **Multi-language Support**: English, Indonesian, and Malay.

## 🛠️ Tech Stack

- **React 18**
- **React Router v6**
- **Vite**
- **Tailwind CSS**
- **Auth0** for authentication
- **Socket.io Client** & **LiveKit Client** for real-time communication
- **Recharts** for data visualization

## 💻 Development

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
Runs on `http://localhost:5173` by default.

### Build for Production

```bash
npm run build
```
Outputs to `dist/`.

## 🧪 Testing

```bash
npm run test
```

⏺ Summary: Cloudflare Proxy Whitelisting

  Based on my research, here's what you need to know:

  The Problem

  When using Cloudflare proxy, the IPs that reach enterprise firewalls are
  Cloudflare's edge servers, not your origin server. These IPs:
  - Are shared across all Cloudflare customers
  - Can change (though infrequently)
  - Include 15 IPv4 ranges and 7 IPv6 ranges

  The Solution

  Don't whitelist individual IPs - Instead, enterprises must whitelist ALL
  Cloudflare IP ranges from:
  - IPv4: https://www.cloudflare.com/ips-v4
  - IPv6: https://www.cloudflare.com/ips-v6

  Better Options for Enterprise Clients

  1. Cloudflare Enterprise Static IPs - Dedicated IPs that never change
  2. Bring Your Own IP (BYOIP) - Use their own IP ranges
  3. Cloudflare Tunnel - No inbound whitelisting needed

  Key Takeaway

  The IPs you provided (104.26.15.116, etc.) are just a few of many possible
  Cloudflare edge servers. Enterprises must whitelist the complete Cloudflare
  IP range, not individual IPs, or they'll experience intermittent connection
  failures.

  I've created a comprehensive guide (CLOUDFLARE_WHITELISTING_GUIDE.md) with
  automation scripts and email templates you can use with enterprise clients.

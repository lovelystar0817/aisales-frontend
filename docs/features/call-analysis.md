# Call Analysis

The **Call Analysis** feature allows you to upload pre-recorded audio files of actual sales calls or practice sessions for AI assessment.

## How to Upload

1.  Navigate to the **Call Analysis** section in the sidebar.
2.  Click **Upload Audio**.
3.  Select a supported audio file from your device (MP3, WAV, M4A).
4.  **Note:** Ensure the file size is within the limit (typically 25MB).

## Processing

Once uploaded, the system performs the following steps:

1.  **Transcription:** Converts the audio to text using a high-accuracy Speech-to-Text engine.
2.  **Diarization:** Identifies different speakers (e.g., Speaker A = Sales Rep, Speaker B = Customer).
3.  **Analysis:** The AI evaluates the conversation against sales frameworks (like MEDDPICC or custom frameworks).

## Viewing Results

After processing is complete (usually within a few minutes), you will see a report similar to the Roleplay Assessment:

*   **Summary:** A concise overview of the call.
*   **Key Moments:** Highlighted critical points in the conversation.
*   **Coaching Tips:** Actionable advice for future calls.
*   **Print/Export:** You can print the report to PDF for your records.
